# Проект «Bouquet»

Интернет-магазин цветов с каталогом товаров, фильтрацией и корзиной.

## Требования

- Node.js 18
- npm

## Установка

```bash
npm install
```

## Команды

| Команда | Описание |
|---------|----------|
| `npm start` | Запуск сервера разработки |
| `npm run build` | Сборка для продакшена |
| `npm run lint` | Проверка кода ESLint |

## Структура проекта

```
├── public/           # Статические файлы
├── src/
│   ├── api-services/ # API-клиенты
│   ├── framework/    # Базовые классы
│   ├── modals/       # Модальные окна
│   ├── model/        # Модели данных
│   ├── presenter/    # Презентеры
│   ├── utils/        # Утилиты
│   ├── vendor/       # Сторонние библиотеки
│   └── views/        # Представления
├── markup/           # Макеты
├── package.json
└── webpack.config.js
```

## Технологии

- Webpack 5
- Babel
- ESLint (htmlacademy)
